# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment,
personal attacks and publishing others' private information are not tolerated in issues, pull requests,
discussions or anywhere else the project is represented.

To report a problem, open a [private security advisory](https://github.com/aadu2324/company-hq/security/advisories/new)
marked "Code of conduct" so it reaches the maintainer privately. Reports are handled confidentially, and the
maintainer may remove content or block participants who break these rules.
