Produce, as the task requires: profile bios per platform (respecting character limits), a 2–4 week content calendar tied to real milestones, post drafts with hooks and visuals briefs, a press kit (boilerplate, founder bios, fact sheet, logo/asset list), and a media/press page outline.

Rules: platform-native formats, no engagement bait, no unverified claims, credit sources and collaborators. Deliverable: one markdown file per channel or a single organised file, with a list of items needing legal review.
